# IBDP Chemistry By Sanjith Chellamuthu

Revision site for IB Chemistry SL (2016 syllabus, topics 1 to 8 and organic chemistry up to addition polymers): every 2022 to 2025 past paper question that fits the syllabus, grouped by paper (Paper 1, Paper 1B, Paper 2) and year, each labelled with its sub topic, with hidden model answers, done and review marks, a progress tracker, notes, formulas and an exam countdown.

## Files

- `index.html` is the whole site (question data, answers, notes, formulas, styles and script).
- `q/` holds the question images cropped from the past papers.

## Hosting on GitHub Pages

Settings, then Pages, then set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.

Progress is stored in the browser you use (localStorage), so it does not carry over between devices.

The question images come from IB past papers. Keep the repository private unless you have permission to share them.
